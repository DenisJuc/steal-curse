# Fusion Board — how it works

## Where to open it

**Collection (left HUD) → Board tab** (between Fusion and Advanced).

After a successful fuse, Collection switches to the Board tab automatically.

## What the Board is

- Fusing a relic **places it on the Board** and uses **1 concurrent slot**.
- Occupied slots show relic art, rank, Charm, and income multiplier.
- Empty unlocked slots say “Fuse on the Fusion tab to fill”.
- Locked slots show the exact unlock (e.g. First Golden `0/1`) — not Rebirth-gated for slot 2.

## Rules (server-authoritative)

| Topic | Rule |
|--------|------|
| Remove / swap / unequip from Board | **Not supported** — no server action. Upgrades improve that relic in place. |
| Income ×rank | Active when that **fused relic is on a pedestal** |
| Hunt Charm | Needs fused relic **on a pedestal** |
| Workshop / Shrine Charms | Apply from the Board entry (Workshop on Essence; Shrine pulse) |
| New fusion vs upgrade | New fuse needs a free slot; rank upgrades never need another slot |

## Slot unlock ladder

1. Starter slot  
2. First Golden mutation goal  
3. Fifteen Unique Mutated goal  
4. Three Epic Catalysts goal  
5. First Rebirth  

Economy / rarity / Rebirth costs are unchanged.
